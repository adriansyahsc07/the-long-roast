A one-sentence satirical roast of lawmakers who would regulate AI, crypto and the internet but cannot convert a file to PDF. The program writes the sentence to $MAKEFUN_OUTPUT_DIR/entry.txt, where make.fun's judge compares it blind, two at a time, against the other entries.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
